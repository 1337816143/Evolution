EVOLUTION / REAL-TIME VECTOR KEYFRAME

实时手势驱动的
矢量关键帧视觉实验

在浏览器中使用本地摄像头和 MediaPipe HandLandmarker 获取手部关键点与手势状态，并以 WebGL2 实时生成可交互的矢量蒙版、时序效果、Scene 多蒙版、轨迹和 GPU 特效。

核心运行链

1. 打开 Studio 并授权本地摄像头→2. MediaPipe HandLandmarker 进行实时手部关键点追踪→3. Gesture FSM 将 pinch / drag / swipe / two-hand transform 转为控制状态→4. WebGL2 渲染矢量蒙版、特效栈、时间效果和 Scene→5. 录制 Canvas 或记录 Motion Keyframes 并回放
核心验收不是“页面能打开”，而是 打开 Studio → 看见实时画面 → 手势被追踪 → 矢量效果随动作实时变化。构建成功、Pages 发布成功和具体设备运行正常分别记录。
