教学解释

1. PCA保留什么

对已明确变换和标准化的矩阵，PCA寻找最大方差方向。成分是原变量的线性组合，不是天然的“可持续性总分”。一个解释方差大的轴，不一定最重要于你的决策问题。

教学解释

2. 聚类选择不是纯技术细节

变量、标准化、距离、连接方式和类别数都影响分组。Ward的最小方差解释对应欧氏几何；若忠实复现一篇报告其他距离组合的研究，应先如实重现并说明限制，再单独做敏感性检查，而不是静默换掉作者方法。

原文方法教学

3. 不要把不同论文设置混用

梁2022的优秀案例聚类与梁2023的PCA后方案分类不是同一步骤。曲周数据文章还采用轮廓系数与后续细分处理。教程可以给通用示例，但不能把教程的默认选项写进原文Methods。

教学代码

4. R最小骨架

Z <- scale(X)
pc <- prcomp(Z, center = FALSE, scale. = FALSE)
# 根据研究目的与解释度选择PC数，不机械固定为2
hc <- hclust(dist(pc$x[, 1:k, drop = FALSE]), method = 'ward.D2')
group <- cutree(hc, k = g)

这是欧氏距离教学实现，不是任何一篇论文的完整原始脚本。下载包另附可运行示例。

教学练习

5. 验收标准

对同一数据分别按原始指标和PCA得分聚类，改变标准化或类别数。记录哪些对象稳定同组、哪些经常换组。给每类写描述而不是道德标签，最后检查它是否有实际管理意义。

PC1可以直接称为总体可持续性吗？

不能，PCA按方差而不是按价值或可持续性准则定义轴。
