可审计的方法，不虚构一个总概率

  1. 目标先统一：按自动额外重置、Banked、公告、个人周期等分别保留。
  2. 来源先去重：明确转引与客户端不重复投票。共享事件数据仍保留依赖说明，不假定不同域名独立。
  3. 时间先对齐：仅相同定义、预测起点、范围与窗口可比较；不把日期中位数插值为 24 小时概率。
  4. 过期 / 冲突先隔离：NextReset 的来源快照已过期，LunarWerx 超过来源注明的新鲜度；取回旧缓存不重置其时钟。
  5. 未来再验证：在窗口结束前归档，结果分为确认发生、确认未发生和未知。未知不当负例。积累样本后才能报告 Brier、可靠性与基线。
